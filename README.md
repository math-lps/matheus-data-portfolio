# Alex Morgan — Data Analyst Portfolio

A one-page portfolio site for a Data Analyst. It uses a minimalist dark navy design with white text and orange accents, and has five sections: Home, About Me, Projects, Skills and Contact.

## Tech

- TanStack Start (React 19) and Tailwind CSS 4
- Netlify hosting, with project images served through Netlify Image CDN

## Personalise it

Every piece of text, link and skill level lives in `src/content/portfolio.ts`. Change the name, intro, email, LinkedIn and GitHub URLs, and the project list there. Project images are in `public/img/`.

## Run locally

```bash
pnpm install
netlify dev   # or: pnpm dev
```
